## 👋 About Me · 关于我

<div align="center">

```yaml

contact:   me@alanzeng.com
```

</div>

I'm a master's student at **Fudan University**. I care about making LLMs genuinely useful for
software engineering — code agents, context engineering, and the messy real-world loop between
research ideas and working tools. Most of what I build starts as something I personally wanted
to exist.

<details>
<summary><b>🧭 What I'm into right now</b></summary>

<br/>

- **AI4SE / LLM for Code** — how coding agents reason about large, unfamiliar codebases
- **Context engineering** — retrieval, memory, and paper-wide context for long documents
- **Agents** — tool-using systems that hold up outside a demo
- **Reinforcement Learning** — still learning it the hard way, one assignment at a time

</details>
